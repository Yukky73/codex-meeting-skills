# 面談後メールの添付資料

## 標準候補

標準候補はローカル設定の `attachments` に利用者が指定したPDFだけとする。未設定のファイル、同じフォルダの別ファイルや別版を自動選択しない。ユーザーが現行チャットで別資料を明示した場合は、その指定を承認対象へ含める。ファイル名のUnicode表現は正規化して照合し、一意に一致した実ファイルを使う。

| 用途 | 設定キー |
| --- | --- |
| プロダクト案内 | `product_guide` |
| 基本料金表 | `standard_pricing` |
| 明示指定時だけ使う特別料金表 | `special_pricing` |
| セキュリティ説明資料 | `security_guide` |
| 公開セキュリティチェックシート | `security_checklist` |

## 選択基準

- プロダクト案内は通常必須。料金表は次の基準で1件だけ選ぶ。
- 料金表は基本料金表を標準とする。ゼネコン・サブコンの顧客でも、ユーザーの明示指示がなければ基本料金表を選ぶ。
- ゼネコン・サブコン向け特別料金表は、ユーザーが現行チャットで使用を明示した場合だけ選択肢に含める。業種、過去の面談での説明・合意だけを根拠に候補化・推奨・添付しない。
- ユーザーの指示が曖昧・矛盾している場合は、基本料金表を推奨候補として理由を示し、選択を確認する。両料金表を一緒に添付して判断を回避しない。
- セキュリティ、データ保護、通信・認証、社内セキュリティ基準などについて説明や社内確認が必要と議事録から読み取れる場合は、セキュリティ説明資料を追加する。単に「安全」などの語が出るだけでは追加しない。
- 情シス・セキュリティ部門の審査、クラウド利用審査、チェックシートや質問票の提出・確認が必要または見込まれる場合は、公開セキュリティチェックシートも追加する。通常の機能・価格検討だけならセキュリティ資料は添付しない。
- ユーザーが現行チャットで添付の追加・除外・料金表を明示した場合はその指定を優先する。選択理由は議事録の具体的な記述またはユーザーの指定に結び付け、一括承認時に提示する。

## 検証

作成ごとに選択したPDFの実在、読み取り可否、先頭のPDFシグネチャ、サイズを確認する。ファイル名だけで内容や改訂の新しさを保証しない。実データを添付し、承認前・作成直前のSHA-256、および作成後の添付メタデータを照合する。資料を別フォルダへ複製・加工したり、文字起こしや内部議事録を追加で添付したりしない。
