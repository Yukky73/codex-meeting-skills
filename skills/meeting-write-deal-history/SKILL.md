# Meeting Deal History Writer

指定された `面談準備/` の完成済み議事録を、対応する HubSpot 取引に紐づく新規 `MEETING_EVENT` として作成する。取引プロパティや既存の予定ミーティングは変更しない。

## 利用者ごとの設定

実行前に [共通設定](../meeting-run-followup/references/configuration.md) を読み、作業ワークスペースの `.meeting-skills.local.md` を確認する。必要な設定が未記入なら、その段階を実行せず不足項目を示す。設定・議事録・承認内容はローカルで扱い、公開リポジトリへ保存しない。相対的なリソースパスは、このスキルの実体ディレクトリを基準に解決する。

## 照合と対象

1. 指定された議事録を読む。会話上で一意に指定できない場合は、候補を示して確認する。
2. `HUBSPOT取引ID` を読み、空欄・複数・不正な値の場合は作成しない。会社名、面談日、担当者名は照合補助として使うが、名前検索で別取引を補完しない。
3. `## 議事録` または `◆議事録` に実質的な内容がない場合は、作成しない。作成途中の原本や文字起こし自体を根拠にしない。
4. HubSpot の利用可能な object type と read/write access を確認してから、取引 ID のレコードを読む。`MEETING_EVENT` の read/write access と、作成に使うプロパティの内部名・値を `search_properties` または `get_properties` で確認する。
5. 対象取引に紐づく既存 `MEETING_EVENT` を検索する。面談日と本文が同一のログがあれば重複作成しない。予定ミーティングの本文が異なる場合は、そのレコードを更新せず新規作成する。

## 作成内容

事前情報の開始位置を確認できなければ作成しない。面談日だけで時刻を確認できず、APIが開始時刻を必須とする場合は時刻を確認する。推測で時刻を設定しない。

- `MEETING_EVENT` を新規作成し、対象 `DEAL` に関連付ける。
- Meeting description (`hs_meeting_body`) には、議事録ファイルの先頭から `## 面談事前情報` または `## 事前情報` の直前までを完全に転記する。本文の語句・順序・情報量は変更せず、HubSpotで読めるHTMLの見出し、段落、箇条書きに構造化する。`## 面談事前情報` または `## 事前情報` とその配下は転記しない。
- Markdownを単一のHTML段落やプレーンテキスト一行へ貼り付けない。見出しは見出し、通常行は段落、連続する箇条書きはリスト、空行は段落境界として、元の改行構造を保持する。
- 面談日・開始時刻は議事録の記載どおりに記録する。終了時刻は議事録または同一面談の既存予定ミーティングで確認できる場合だけ設定し、推測しない。
- Meeting outcome は、完成済み議事録で実施を確認できる場合だけ `COMPLETED` にする。
- Meeting name は、議事録にある会社名・担当者名・面談種別から簡潔に作る。議事録にない情報は補わない。
- 既存の予定ミーティング、取引プロパティ、他の活動ログは変更しない。

## 書き込みと検証

`manage_crm_objects` の確認要件に従う。対象取引・本文・関連付けの明示承認を取得する。親スキルの一括承認が対象・内容を含む場合は再確認しない。承認を得た場合だけ、最大10件ずつ作成し、対象 `DEAL` への関連付けを同時に作成する。

| Object Type | ID | Property | Current Value | New Value |
| --- | ---: | --- | --- | --- |
| MEETING_EVENT | 新規 | Meeting description | 空 | `## 面談事前情報` または `## 事前情報` より前をHubSpot用HTMLで構造化した完全転記本文 |

作成後はミーティングログを再取得し、本文が完全転記され、取引への関連付けが作成されたことを確認する。HTMLをテキストとして読み戻した結果で、見出し・各行・箇条書き・空行の境界が原本と一致し、一行に連結されていないことまで検証する。

## 報告

- 作成したミーティングログの HubSpot URL（HubSpot が返す UTM 付き URL）と、反映元の議事録ファイルのパスを示す。
- 作成しなかった場合は、照合不能、内容不足、重複、承認待ちなどの理由を明示する。
